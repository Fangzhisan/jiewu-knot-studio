# 编织课程目标与完成情况

编织以246节为扩展目标，与绳结的目标规模一致。这是本站的课程规划，不是外部网站的246节编织清单。

当前可播放三维课42节，其中本批30节已独立检查过程、布线、转折、收尾、收紧、成品和浏览器。原有12节保留，但没有自动套用本轮验收。按七项复核口径，仍有216项目标需制作或复核。规划条目不进入前台课程数量。

新课逐节检查1001帧的整绳互穿、弯曲半径和长度保持，另检查换行、换股与阶段连接。数值检查与浏览器画面检查分别进行；只有全部通过才登记模型指纹。它们是动画复核，不等于实物工艺认证。

网具区分实际网结和装饰结网；首饰编绳段与完整饰品分开；组织小样不冒充已经离机锁边的成品。每课的具体演示范围写在课程说明中。

工艺参考：[Animated Knots 的网结与制网说明](https://www.animatedknots.com/sheet-bend-knot)、[多股对称平编](https://www.animatedknots.com/french-sinnet-knot-one)、[Cotton Incorporated 的织造顺序与基础组织](https://cottonworks.com/wp-content/uploads/2023/03/Weaving-101.pdf)。模型由本站程序生成。
